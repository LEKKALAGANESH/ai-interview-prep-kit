# Quality Scorecard

The evaluation layer should report at least:

- schema-valid cases
- successful/failed cases
- must-have coverage
- requirement relevance
- specificity
- groundedness
- answer usefulness
- diversity
- difficulty fit
- provider/model
- prompt versions
- latency and attempts when available

Deterministic contract and coverage failures are release blockers. Semantic judge scores are advisory and are used for regression analysis, not to make an invalid kit shippable.
